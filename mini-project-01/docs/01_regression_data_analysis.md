## 2. 데이터 분할 및 누수 확인 (CP-02)

**분석:** 세 집합의 `cnt` 평균이 서로 다르다면, 그 차이가 이후 모델 평가에 어떤 영향을 줄지 1~2문장으로 작성합니다.

## 3. 상관관계 및 입력 특성 분석 (CP-02)

- **`temp`와 `cnt`의 상관관계:** 0.398  약한 중간정도의 양의 상관관계
- **`hum`과 `cnt`의 상관관계:** -0.301  음의 상관관계
- **`windspeed`와 `cnt`의 상관관계:** 0.094  매우약한 양의 상관관계
- **`temp`와 `atemp`의 상관관계:** 0.992  상관관계가 매우 높고 거의 비슷한 움직임을 보임.
- **사용한 특성 목록(`FEATURES`):** FEATURES = [
    "season",
    "yr",
    "mnth",
    "hr",
    "holiday",
    "weekday",
    "workingday",
    "weathersit",
    "temp",
    "atemp",
    "hum",
    "windspeed"
]
TARGET = "cnt"
  (선택 근거는 `adr.md` 의사결정 ①에 작성)

**분석:** 상관관계에서 알게 된 점과 상관계수만으로 특성을 결정할 수 없는 이유를 간단히 작성합니다.  
상관계수는 선형 관계만 나타내며 인과관계를 의미하지 않는다. 또한 상관계수가 낮더라도 비선형 관계가 존재할 수 있고, 실제 예측 성능에 도움이 되는 특성일 수도 있다. 따라서 상관계수만으로 특성을 제거하지 않고 모델 학습 및 성능 비교를 통해 최종 특성을 결정해야 한다.
